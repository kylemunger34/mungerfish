This is one of my passion projects I've wanted to build for a while and finally got time this fall. My Dad and I make one or two fishing trips to Saginaw Bay every year, in an effort to bring in a massive walleye haul. However, we run 8 rods at a time, and often find ourselves getting caught up in the fish and never remembering what we caught them on, and often just end up picking baits and weights at random. 

This web app designed for my IPhone attempts to eliminate this by providing detailed recording and analysis of the fish we catch. It also allows us to track what is on each rod, so we don't have to pull them in to know what is on them. For the type of fishing we are doing, I believe this structure of app is superior to other fishing recording apps out there. I could not find the software I desired, so I built it. 

It is deployed through Render, and can be accessed here: https://mungerfish-lsnp.onrender.com

Enjoy!

(ps this web app is kind of just for me so there's no user accounts and we share one database, but feel free to test it out! The fish recorded in there are just test fish right now)
